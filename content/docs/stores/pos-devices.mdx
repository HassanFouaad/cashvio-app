## What are POS Devices?

A **POS device** is a register (tablet, phone, or terminal) running the Cashvio POS app at your store. Each device is registered under a store and paired securely with a **one-time code (OTP)**, so there are no shared passwords.

<Callout title="Note">
The POS tab appears when the **POS module** is enabled in your plan. The number of devices per store depends on your plan's device limit.
</Callout>

## Adding a Device

1. Go to **Settings > Stores**, open your store, and select the **POS** tab.
2. Click **Add Device** and give the device a **name** (e.g., "Front Counter").
3. A **pairing code** appears: a one-time numeric code with an expiry time.
4. On the POS device, open the Cashvio POS app and **enter the code**.
5. Once paired, the device status changes from **Pairing** to **Active**.

### Regenerating the Pairing Code

If the code expires before you use it, open the device's menu and choose **Pair** to view or **regenerate** a fresh code.

## Device Statuses

| Status | Meaning |
|--------|---------|
| **Pairing** | Device created, waiting to be paired with the code |
| **Active** | Device is paired and can process sales |
| **Disabled** | Device is blocked from use (can be re-enabled) |

## Managing Devices

From each device's actions menu you can:

- **Edit**: rename the device
- **Disable / Enable**: temporarily block or restore the device without deleting it
- **Delete**: permanently remove the device

<Callout title="Tip">
Name devices by their physical location ("Front Counter", "Drive-Thru Window") so shift reports and troubleshooting stay clear.
</Callout>
