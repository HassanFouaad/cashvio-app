## What are Roles?

A **role** defines what a team member can see and do in Cashvio. Each role has a set of **permissions** that control access to different features. For example, a "Cashier" role might only have permission to create orders, while a "Manager" role might have full access.

## How Permissions Work

Cashvio has fine-grained permissions in the format *action : resource*, grouped by resource. The main groups are:

| Resource | Available Permissions |
|----------|-----------------------|
| **Orders** | View, Create, Edit, Cancel |
| **Products** | View, Create, Edit, Delete |
| **Categories** | View, Create, Edit, Delete |
| **Customers** | View, Create, Edit, Delete |
| **Inventory** | View, Adjust, Transfer, Edit reorder point |
| **Payments** | View, Create, Edit |
| **Suppliers** | View, Create, Edit, Delete |
| **Purchase Orders** | View, Create, Edit, Delete, Approve, Receive, Cancel |
| **Returns** | View, Create, Edit, Approve, Reject, Cancel |
| **Refunds** | View, Create, Process, Cancel |
| **Coupons** | View, Create, Edit, Delete |
| **POS Devices** | View, Create, Edit, Delete |
| **Users** | View, Invite, Edit, Deactivate, Assign role |
| **Roles** | View, Create, Edit, Delete |
| **Stores** | View, Create, Edit, Delete |
| **Business** | Branding and business-level permissions |

<Callout title="Note">
When you grant any action on a resource, its **View** permission is added automatically — you can't edit what you can't see.
</Callout>

## Creating a Role

1. Go to **Roles & Permissions** (or **الأدوار والصلاحيات** in Arabic) in the sidebar.
2. Click **Create Role**.
3. Fill in:

| Field | Description |
|-------|-------------|
| **Role Name** | A name for this role (e.g., "Cashier", "Warehouse Staff") |
| **Description** | An optional description of what this role is for |

4. Select the **permissions** for this role. Permissions are organized by resource — each group has a select-all option.
5. Click **Save**.

<Callout title="Business-wide or per store">
The role itself defines *what* someone can do. *Where* they can do it is decided when you [assign the role to a user](/docs/team/users) — business-wide, or scoped to a single store.
</Callout>

## Editing a Role

1. Go to **Roles & Permissions** in the sidebar.
2. Click on the role you want to edit.
3. Update the name, description, or permissions.
4. Click **Save Changes**.

## How Roles Affect the Interface

When a user logs in, their role determines:

- **Which sidebar menu items they see** — Only modules they have "View" permission for appear.
- **Which actions they can perform** — Buttons like "New Sale" or "Delete Product" only appear if the user has the corresponding permission.
- **Which Dashboard quick actions appear** — Only actions the user is allowed to perform are shown.

<Callout title="Important">
The account owner (business owner) always has full access to everything, regardless of role settings. Roles only restrict invited team members.
</Callout>

## Default Roles vs Custom Roles

Cashvio provides three ready-made **system roles** that cannot be edited (marked "System role" in the list):

- **Tenant Admin** — full access to everything
- **Cashier** — day-to-day selling
- **Accountant** — financial visibility

You can create as many **custom roles** as you need on top of them — for example a "Warehouse Staff" role limited to inventory and purchase orders.
