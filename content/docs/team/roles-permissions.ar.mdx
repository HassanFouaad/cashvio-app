## ما هي الأدوار؟

**الدور** يحدد ما يمكن لعضو الفريق رؤيته وفعله في كاشفيو. كل دور له مجموعة من **الصلاحيات** التي تتحكم في الوصول للميزات المختلفة. مثلاً، دور "أمين الصندوق" قد يكون لديه صلاحية إنشاء الطلبات فقط، بينما دور "المدير" قد يكون لديه وصول كامل.

لكل عضو فريق **دور واحد في نشاطك التجاري**. اختر دوره، ثم حدّد أين يمكنه استخدامه: **وصول على مستوى النشاط التجاري (كل المتاجر)** أو **المتاجر المعيّنة**. يُطبّق الدور نفسه على كل متجر تختاره.

مثلاً، الموظف الذي يعمل في فرعين له دور **أمين الصندوق** واحد مع اختيار المتجرين. وللموظف الذي يجمع بين مهام مختلفة، أنشئ دورًا مخصصًا واحدًا بالصلاحيات التي يحتاجها.

## كيف تعمل الصلاحيات

صلاحيات كاشفيو دقيقة بصيغة *إجراء : مورد*، ومجمعة حسب المورد. أهم المجموعات:

| المورد | الصلاحيات المتاحة |
|--------|-------------------|
| **الطلبات** | عرض، إنشاء، تعديل، إلغاء |
| **المنتجات** | عرض، إنشاء، تعديل، حذف |
| **الأقسام** | عرض، إنشاء، تعديل، حذف |
| **العملاء** | عرض، إنشاء، تعديل، حذف |
| **المخزون** | عرض، تعديل، نقل، تعديل حد إعادة الطلب |
| **المدفوعات** | عرض، إنشاء، تعديل |
| **الموردون** | عرض، إنشاء، تعديل، حذف |
| **أوامر الشراء** | عرض، إنشاء، تعديل، حذف، اعتماد، استلام، إلغاء |
| **المرتجعات** | عرض، إنشاء، تعديل، اعتماد، رفض، إلغاء |
| **الاستردادات** | عرض، إنشاء، معالجة، إلغاء |
| **الكوبونات** | عرض، إنشاء، تعديل، حذف |
| **أجهزة الكاشير** | عرض، إنشاء، تعديل، حذف |
| **الخزائن** | عرض، إضافة، تعديل ([جلسات الخزينة](/ar/docs/orders/cash-sessions)) |
| **جلسات الخزينة** | عرض الإجماليات، فتح، إغلاق، تسجيل الإيداع والسحب |
| **درج النقدية** | فتح بدون بيع |
| **سجل جلسات الخزينة** | عرض |
| **المستخدمون** | عرض، دعوة، تعديل، إيقاف، إسناد دور |
| **الأدوار** | عرض، إنشاء، تعديل، حذف |
| **المتاجر** | عرض، إنشاء، تعديل، حذف |
| **النشاط التجاري** | صلاحيات الشعار وإعدادات مستوى النشاط |

<Callout title="ملاحظة">
عند منح أي إجراء على مورد، تُضاف صلاحية **العرض** تلقائياً، فلا يمكن التعديل دون الرؤية.
</Callout>

## الإسنادات المحددة والفرع المختار

الصفحات التشغيلية (الطلبات، المخزون، POS، إعدادات المتجر الإلكتروني) تُقيّم الصلاحيات في سياق **الفرع المختار**. الكاشير المعيّن في فرع أ لا يصل إلى فرع ب إلا إذا اخترت له فرع ب أيضًا.

خيار **وصول على مستوى النشاط التجاري (كل المتاجر)** يشمل المتاجر الحالية وأي متجر تضيفه لاحقًا. أما اختيار متاجر محددة، فيحصر الوصول فيها فقط.

عضو الفريق المُسنَد إلى عدة فروع يعمل فيها جميعاً. القوائم مثل خصومات الأسعار، وتقييمات المنتجات، وأسعار الفروع، واستيراد المنتجات، وزيارات المتجر تشمل كل فرع يملك فيه الصلاحية. والإجراءات مثل نقل المخزون تعمل بين أي فرعين من فروعه.

دور **مدير النشاط التجاري** يتيح دائمًا الوصول على مستوى النشاط كله. يجب أن يبقى مدير واحد على الأقل نشطاً؛ البوابة تمنع التغييرات التي تُزيل آخر مدير نشط.

### منح الصلاحيات للآخرين

لا يمكنك منح صلاحية إلا إذا كنت تملكها بنفس النطاق:

- عند إنشاء دور أو تعديله، يمكنك إضافة الصلاحيات التي تملكها على مستوى النشاط فقط.
- عند إسناد دور، تحتاج إلى كل صلاحياته على مستوى النشاط إذا كان الإسناد على مستوى النشاط، أو في ذلك الفرع إذا كان الإسناد لفرع.
- إنشاء فرع جديد يتطلب صلاحية الفروع على مستوى النشاط.
- الكوبونات والتكاملات تتبع فرعها: عضو الفريق صاحب الصلاحية على مستوى الفرع يرى ويدير كوبونات وتكاملات فروعه فقط.

## كيف تؤثر الأدوار على الواجهة

عند تسجيل دخول المستخدم، تحدد إسناداته:

- **عناصر القائمة الجانبية المرئية**: يحدد الدور الصفحات المتاحة؛ وتلتزم إجراءات الفرع بالمتاجر المعيّنة للمستخدم.
- **الإجراءات التي يمكنه تنفيذها**: تظهر أزرار مثل "بيع جديد" أو "حذف منتج" فقط عندما تكون الصلاحية سارية في سياق الفرع (أو على مستوى النشاط عندما لا يُطلب فرع).
- **الإجراءات السريعة في لوحة التحكم**: تظهر فقط الإجراءات المسموح للمستخدم بتنفيذها.

<Callout title="مهم">
دور **مدير النشاط التجاري** يشمل إدارة النشاط والوصول إلى POS. لا يحتاج المدير إلى دور أمين صندوق إضافي. تغيير دور المستخدم يستبدل دوره السابق.
</Callout>
