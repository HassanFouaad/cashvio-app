## ما هي الأدوار؟

**الدور** يحدد ما يمكن لعضو الفريق رؤيته وفعله في كاشفيو. كل دور له مجموعة من **الصلاحيات** التي تتحكم في الوصول للميزات المختلفة. مثلاً، دور "أمين الصندوق" قد يكون لديه صلاحية إنشاء الطلبات فقط، بينما دور "المدير" قد يكون لديه وصول كامل.

## كيف تعمل الصلاحيات

صلاحيات كاشفيو دقيقة بصيغة *إجراء : مورد*، ومجمعة حسب المورد. أهم المجموعات:

| المورد | الصلاحيات المتاحة |
|--------|-------------------|
| **الطلبات** | عرض، إنشاء، تعديل، إلغاء |
| **المنتجات** | عرض، إنشاء، تعديل، حذف |
| **الأقسام** | عرض، إنشاء، تعديل، حذف |
| **العملاء** | عرض، إنشاء، تعديل، حذف |
| **المخزون** | عرض، تعديل، نقل، تعديل حد إعادة الطلب |
| **المدفوعات** | عرض، إنشاء، تعديل |
| **الموردون** | عرض، إنشاء، تعديل، حذف |
| **أوامر الشراء** | عرض، إنشاء، تعديل، حذف، اعتماد، استلام، إلغاء |
| **المرتجعات** | عرض، إنشاء، تعديل، اعتماد، رفض، إلغاء |
| **الاستردادات** | عرض، إنشاء، معالجة، إلغاء |
| **الكوبونات** | عرض، إنشاء، تعديل، حذف |
| **أجهزة الكاشير** | عرض، إنشاء، تعديل، حذف |
| **المستخدمون** | عرض، دعوة، تعديل، إيقاف، إسناد دور |
| **الأدوار** | عرض، إنشاء، تعديل، حذف |
| **المتاجر** | عرض، إنشاء، تعديل، حذف |
| **النشاط التجاري** | صلاحيات الشعار وإعدادات مستوى النشاط |

<Callout title="ملاحظة">
عند منح أي إجراء على مورد، تُضاف صلاحية **العرض** تلقائياً، فلا يمكن التعديل دون الرؤية.
</Callout>

## إنشاء دور

1. اذهب إلى **الأدوار والصلاحيات** في القائمة الجانبية.
2. انقر على **إنشاء دور**.
3. املأ:

| الحقل | الوصف |
|-------|-------|
| **اسم الدور** | اسم لهذا الدور (مثل: "أمين صندوق"، "موظف مخزن") |
| **الوصف** | وصف اختياري لما هذا الدور |

4. اختر **الصلاحيات** لهذا الدور. الصلاحيات منظمة حسب المورد، ولكل مجموعة خيار تحديد الكل.
5. انقر على **حفظ**.

<Callout title="على مستوى النشاط أم الفرع؟">
الدور نفسه يحدد *ماذا* يستطيع الشخص أن يفعل. أما *أين* فيتحدد عند [إسناد الدور للمستخدم](/ar/docs/team/users): على مستوى النشاط كله أو مقصوراً على فرع واحد.
</Callout>

## تعديل دور

1. اذهب إلى **الأدوار والصلاحيات** في القائمة الجانبية.
2. انقر على الدور الذي تريد تعديله.
3. حدّث الاسم أو الوصف أو الصلاحيات.
4. انقر على **حفظ التغييرات**.

## كيف تؤثر الأدوار على الواجهة

عند تسجيل دخول المستخدم، يحدد دوره:

- **عناصر القائمة الجانبية المرئية**: تظهر فقط الوحدات التي لديه صلاحية "عرض".
- **الإجراءات التي يمكنه تنفيذها**: تظهر أزرار مثل "بيع جديد" أو "حذف منتج" فقط إذا كان لديه الصلاحية المقابلة.
- **الإجراءات السريعة في لوحة التحكم**: تظهر فقط الإجراءات المسموح للمستخدم بتنفيذها.

<Callout title="مهم">
صاحب الحساب (المالك) لديه دائماً وصول كامل لكل شيء، بغض النظر عن إعدادات الأدوار. الأدوار تقيد فقط أعضاء الفريق المدعوين.
</Callout>

## الأدوار الجاهزة مقابل المخصصة

يوفر كاشفيو ثلاثة **أدوار نظام** جاهزة لا يمكن تعديلها (تظهر بعلامة "دور نظام"):

- **مدير النشاط**: وصول كامل لكل شيء
- **أمين الصندوق**: البيع اليومي
- **المحاسب**: الاطلاع على البيانات المالية

ويمكنك إنشاء أي عدد من **الأدوار المخصصة** فوقها، مثل دور "موظف مخزن" مقصور على المخزون وأوامر الشراء.
