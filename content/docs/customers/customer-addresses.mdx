---

Each customer can have multiple addresses for delivery orders. Manage them from the **Addresses** section on the customer details page.

## Adding an Address

1. Open the customer's details page.
2. In the **Addresses** section, click **Add New Address**.
3. Fill in the address details:

| Field | Description |
|-------|-------------|
| **Address Type** | Apartment, House, or Office |
| **Country / City** | Selected from lists (city depends on the country) |
| **Region** | Required; the area or district |
| **Contact Phone** | Required; defaults to the customer's phone |
| **Street / Building / Floor / Apartment / ZIP** | Detailed address fields |
| **Additional Details** | Any extra delivery instructions |
| **Default Address** | Check to make this the default delivery address |

4. Click **Save**.

You can **edit** or **delete** any address from its card.

<Callout title="Tip">
When creating a delivery order, the customer's default address is filled in automatically, but you can pick any of their saved addresses.
</Callout>
