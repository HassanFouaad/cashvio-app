Every order in Cashvio follows a fixed calculation flow. Use the cards below for tax, discounts, fees, and profit details.

## How Order Totals are Calculated

```
Subtotal = Sum of (item price × quantity) for all items
+ Service Fee (if applicable)
+ Delivery Fee (if applicable)
- Discount (if applied)
+ Tax
= Order Total
```

## Subtotal

The **subtotal** is the sum of all items in the order before any fees, discounts, or tax:

**Subtotal = Item 1 Price × Qty + Item 2 Price × Qty + ...**

Example:
| Item | Price | Qty | Line Total |
|------|-------|-----|------------|
| T-shirt (M/Blue) | 150 EGP | 2 | 300 EGP |
| Jeans (L) | 350 EGP | 1 | 350 EGP |
| **Subtotal** | | | **650 EGP** |

## Full Calculation Example

| Line | Calculation | Amount |
|------|-------------|--------|
| T-shirt × 2 | 150 × 2 | 300 EGP |
| Jeans × 1 | 350 × 1 | 350 EGP |
| **Subtotal** | | **650 EGP** |
| Discount (10%) | 650 × 0.10 | -65 EGP |
| **After Discount** | | **585 EGP** |
| Service Fee (10%) | 585 × 0.10 | 58.50 EGP |
| **Taxable Amount** | | **643.50 EGP** |
| Tax (14%) | 643.50 × 0.14 | 90.09 EGP |
| Delivery Fee | Fixed | 30 EGP |
| **Order Total** | | **763.59 EGP** |
