## ما هي لوحة التحكم؟

**لوحة التحكم** هي أول شاشة تراها بعد تسجيل الدخول. ترحب بك، وتعرض أداء تجارتك للفترة المختارة، وتنبهك لأي شيء يحتاج انتباهك، وتعطيك اختصارات لأكثر المهام استخداماً.

في أعلى لوحة التحكم يمكنك تغيير الفترة الزمنية لكل الأرقام والرسوم: **اليوم**، **هذا الأسبوع**، أو **هذا الشهر**.

## الشريط الإرشادي

تحت الترحيب مباشرة، قد تعرض لوحة التحكم **شريطاً واحداً قابلاً للإغلاق** بخطوة مهمة تالية — مثل تفعيل متجرك الإلكتروني أو تثبيت التطبيق على جهازك. بعد إغلاقه أو إتمام الخطوة يختفي.

## الإجراءات السريعة

صف من الاختصارات يوصلك بضغطة واحدة لأكثر المهام تكراراً:

| الإجراء | ماذا يفعل |
|---------|-----------|
| **بيع جديد** | يفتح شاشة البيع (الكاشير) بملء الشاشة |
| **عرض الطلبات** | يفتح قائمة الطلبات |
| **عرض المنتجات** | يفتح كتالوج المنتجات |
| **إدارة المخزون** | يفتح قائمة المخزون |
| **إضافة عميل** | يفتح نموذج عميل جديد |

<Callout title="مهم">
لوحة التحكم تتكيف مع **صلاحياتك وباقتك**. لا ترى إلا الاختصارات والأقسام المسموح لك بالوصول إليها.
</Callout>

## يحتاج انتباهك

قائمة **يحتاج انتباهك** تعرض الأمور العاجلة بأعدادها، وكل سطر يفتح القائمة المفلترة مباشرة:

- **طلبات معلقة** — طلبات تنتظر المعالجة
- **طلبات غير مدفوعة** — طلبات عليها مبالغ مستحقة
- **دفعات متأخرة** — دفعات مجدولة تجاوزت موعدها
- **مخزون منخفض** — منتجات وصلت لحد إعادة الطلب أو أقل
- **مرتجعات معلقة** — طلبات إرجاع تنتظر المراجعة

إذا لم يوجد شيء عاجل، يختفي هذا القسم تماماً.

## نظرة عامة على المبيعات

أربع بطاقات تلخص أداءك للفترة المختارة، مع مقارنة بالفترة السابقة:

| البطاقة | ماذا تعرض |
|---------|-----------|
| **إجمالي الإيرادات** | المبالغ المحصلة خلال الفترة |
| **إجمالي الطلبات** | عدد الطلبات المنشأة |
| **متوسط قيمة الطلب** | الإيرادات مقسومة على عدد الطلبات |
| **إجمالي الربح** | الإيرادات ناقص تكلفة المنتجات |

تحت البطاقات، رسمان بيانيان يعرضان **زيارات المتجر** و**أفضل المنتجات**. اضغط **عرض الكل** لفتح قسم [التقارير](/ar/docs/reports/analytics-reports) الكامل.

## القائمة الجانبية

على يمين الشاشة (أو يسارها في الإنجليزية) توجد **القائمة الجانبية** — قائمة مسطحة بالأقسام الرئيسية، مع زر **بيع جديد** مثبت دائماً:

| العنصر | ماذا يغطي |
|--------|-----------|
| **لوحة التحكم** | النظرة العامة الرئيسية |
| **المبيعات** | الطلبات — مع تبويبات للمرتجعات والاستردادات والدفعات المتأخرة |
| **الكتالوج** | المنتجات — مع تبويبات للأقسام والخيارات والكوبونات |
| **المخزون** | المخزون — مع تبويبات للمخزون المنخفض والتعديلات وأوامر الشراء والموردين |
| **العملاء** | قائمة العملاء وملفاتهم |
| **المتجر الإلكتروني** | إعدادات متجرك الإلكتروني |
| **التقارير** | التحليلات والتقارير |
| **الفريق** | المستخدمون — مع تبويب للأدوار والصلاحيات |
| **الإعدادات** | الإعدادات العامة والمتاجر والقنوات والباقة والحساب |

الصفحات المرتبطة ببعضها تظهر **كتبويبات أعلى كل قسم** وليس كقوائم فرعية. مثلاً عند فتح **المبيعات** تجد تبويبات: الطلبات، المرتجعات، الاستردادات، الدفعات المتأخرة.

على **الجوال**، تتحول القائمة الجانبية إلى **شريط تنقل سفلي** بأهم العناصر. اضغط **المزيد** للوصول لبقية الأقسام.

## البحث السريع

اضغط **Ctrl+K** (أو **Cmd+K** على ماك)، أو اضغط **أيقونة البحث** في الشريط العلوي، لفتح **البحث السريع**. اكتب ما تريد للانتقال لأي صفحة أو إجراء مباشرة — مثل "الاستردادات" أو "إضافة منتج" — بدون التنقل في القوائم.

## اللغة والمظهر والدعم

في **الشريط العلوي** تجد:

- **تبديل اللغة** — انتقل بين العربية والإنجليزية فوراً.
- **قائمة الحساب** — بدّل بين **الوضع الداكن** و**الفاتح**، أو افتح إعدادات حسابك، أو سجّل الخروج.
- **الدعم** — افتح محادثة الدعم المباشرة.
