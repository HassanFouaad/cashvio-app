title: Contacting Support
description: Send a written request, keep its reference, and retry safely if receipt is uncertain.
---

## Send a written request

Open the [contact form](/contact), choose your inquiry type, and describe what you need help with. Enter contact details the team can use for follow-up, then press **Send Message**.

## Keep your request reference

When **Request received** appears, your message is recorded. Save the **Request reference** shown below it and include that reference when following up with the team.

Receiving a reference does not mean a team member has already read, answered, or resolved the question.

## Retry an uncertain submission

If receipt cannot be confirmed, keep the form open and choose **Retry saved request**. The form retries the saved details instead of creating another submission merely because the first response was lost.

If you edit the details while the previous receipt is uncertain, the form asks you to retry the saved request first. Choosing **Retry saved request** restores those saved details.

After a confirmed receipt, use **Send another message** to start a separate request.
