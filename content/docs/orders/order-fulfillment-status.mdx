## Updating Fulfillment Status

To update an order's fulfillment status:

1. Open the order details.
2. Click **Update Fulfillment Status**.
3. Select the new status from the available options (you can skip ahead, e.g., straight from Pending to Completed) and add optional notes.
4. Confirm the update.

The available statuses depend on the current status and fulfillment method. See [Fulfillment Methods](/docs/stores/fulfillment-methods) for the full status flow.

<Callout title="Note">
**In-Store** orders don't have fulfillment tracking; the customer receives the items immediately. Fulfillment updates are also unavailable once an order is completed or cancelled.
</Callout>

## Cancelling an Order

1. Open the order details.
2. Click **Cancel Order**.
3. Confirm the cancellation.

<Callout title="Note">
Only **Pending** orders can be cancelled. Cancelling reverses inventory changes if inventory tracking was enabled, so stock levels return to what they were before the order.
</Callout>
