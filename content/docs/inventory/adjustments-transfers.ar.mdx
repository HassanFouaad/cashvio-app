أحياناً تحتاج لتغيير مستويات المخزون يدوياً، مثلاً بعد جرد فعلي أو عند تلف عناصر أو لتصحيح خطأ.

## كيفية تعديل المخزون

1. اذهب إلى **المخزون** في القائمة الجانبية.
2. ابحث عن إصدار المنتج وافتح **قائمة الإجراءات** الخاصة به.
3. اختر الإجراء:

| الإجراء | الوصف |
|---------|-------|
| **تعديل المخزون** | زد أو أنقص بكمية + / -، وتعرض النافذة المخزون قبل وبعد. وعند **الإضافة** يمكنك إدخال **تكلفة الوحدة** (تُستخدم في تقارير الأرباح). السبب اختياري. |
| **استهلاك / تالف** | تسجيل وحدات تالفة أو مستهلكة تُزال من المخزون. **السبب مطلوب**. |

4. اضغط **تأكيد**، فيتحدث المخزون فوراً.

## عرض سجل التعديلات

اذهب إلى **المخزون > التعديلات** لرؤية سجل كل تغييرات المخزون:

| العمود | الوصف |
|--------|-------|
| **المنتج / الإصدار** | أي عنصر تغير |
| **النوع** | سبب التغيير: بيع، مرتجع، شراء، نقل وارد/صادر، جرد يدوي، فاقد، تالف، أو غير ذلك |
| **الكمية** | التغيير والمخزون قبل وبعد |
| **السبب** | الملاحظة المسجلة مع التغيير |
| **التاريخ / المستخدم** | متى حدث ومن قام به |

يمكنك التصفية حسب المتجر ونوع التعديل والتاريخ. العمليات التلقائية (البيع والمرتجعات وأوامر الشراء والنقل) تُسجل هنا بجانب تعديلاتك اليدوية: سجل تدقيق كامل.
